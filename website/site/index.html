02 / Inside the blueprint

Your setup is just files.

See where the decisions live. Keep them in Git, review the changes, and make the setup your own.

Explore blueprint structure ↗
[~/] your-blueprint Example files
Explore blueprint files

smu.toml

[provisioning]
adapter = "rcm"

[profile.default]
modules = ["example"]

Choose an adapter and the modules for a profile. This example uses the starter blueprint’s example module.

Understand profiles ↗

dotfiles/rcrc

TAGS="work example smu"
EXCLUDES="base modules utilities"

Use rcm tags to select groups of dotfiles. Put your files in dotfiles/tag-work/ and preview the links before applying them.

Organize your dotfiles ↗

dotfiles/modules/example/

your-blueprint/
└─ dotfiles/
   └─ modules/
      └─ example/

The starter blueprint includes a custom module. Use it as a starting point for work that belongs to your setup.

06 / Field notes

          
Before the first run.

          
Bring over your dotfiles, check the plan, and know where to look if setup stalls.

        

        

          

            Bring your dotfilesCan I bring my existing dotfiles?
            

              
Start from a blueprint you control and add your files to it. In the rcm flow, tags group files and smu --lsrc previews the links.

              

                Read the dotfiles guide →
                
                  
                
              

            

          

          

            Review the planWhat does a plan actually show?
            

              
smu plan summarizes the blueprint, adapter, modules, and potential dotfile conflicts. Review that output and the module sources before applying anything.

              

                Read the quick start →
                
                  
                
              

            

          

          

            Keep it currentHow do updates work?
            

              
Update the blueprint, installer, and modules separately or preview a combined update with smu update --all --dry-run.

              

                Read the updates guide →
                
                  
                
              

            

          

          

            TroubleshootWhere do I look when setup stalls?
            

              
Start with smu doctor and the failing command’s output. Check that the module matches your platform and selected provisioning adapter.
